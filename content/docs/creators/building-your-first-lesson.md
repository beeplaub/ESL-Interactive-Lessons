## Start with lesson settings

Create a lesson from the lesson builder. Set the title, level, topic, cover media, outcomes, and optional timer. Use **Draft** while you are building; publish only when learners should be able to access it.

## Add slides and content

Slides can contain headings, text, lists, grammar explanations, reading passages, images, audio, video, dialogues, flashcards, callouts, and other reusable content blocks. The slide header already carries the title, so do not add a duplicate heading block unless you need a second heading inside the content.

## Add practice

Choose an activity by skill category. Every scored question can hold points, weighting, a lesson outcome, skill/subskill, and learning targets. Use the learner preview to check the actual responsive experience before publishing.

## Save with confidence

The builder saves work quietly in the background and provides undo and redo controls for local changes. Use the activity bank to insert a copy of a reusable activity; the original stays safely in the bank.
