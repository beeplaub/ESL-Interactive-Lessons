## Build outcomes at two levels

Create **course outcomes** for what the whole course should enable. Create **lesson outcomes** for what learners should be able to do after a lesson. A reusable lesson can sit in more than one course, so its lesson outcomes are mapped to course outcomes at the course placement level.

## Map every scored question

Inside each activity or quiz question, select the relevant lesson outcome where appropriate, then set the primary skill, optional subskill, learning targets, maximum points, and analytical weight.

## Choose evidence policy carefully

Courses can use **latest**, **best**, or **first** attempt evidence. BrenUp reports both attainment and coverage. An outcome is only attained when performance reaches the mastery threshold *and* enough mapped evidence has been attempted.

## Keep targets reusable

Learning targets can represent vocabulary, grammar concepts, functional language, pronunciation targets, or other teachable items. Reuse them across questions to build a more meaningful language profile over time.
