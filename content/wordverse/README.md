# Balanced advanced vocabulary pack

240 original teaching entries: 80 Work & Business, 80 Travel & Movement, and 80 Society & Ideas. Added to the September 7 baseline (100 Communication, 20 per other topic), this produces 100 per topic without deleting or replacing existing words.

Headword membership, selected part of speech, and CEFR were checked on 2026-09-07 against the [Oxford 5000 advanced extension](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_5000.pdf). This extension adds 2,000 B2–C1 words to the Oxford 3000. The pack covers 240 of these headwords; it does not claim complete Oxford 5000 coverage, Oxford endorsement, or that existing vocabulary has been verified.

Definitions, examples, collocations, grammar patterns, word-family forms, Bengali glosses, register labels, and learner notes are original editorial drafts. Oxford dictionary definitions/examples have not been imported. Pronunciation, origin, and audio remain blank until they are individually verified; unsupported synonym/antonym claims are omitted. The existing device speech feature can pronounce words, but is not an Oxford audio recording.

Use `/admin/wordverse` to inspect/edit the pack, save drafts, then explicitly publish reviewed drafts. All writes require a fresh platform-admin check. Imports preserve existing IDs, published content and learner progress. Real RELATED edges are saved before publication; these are editorial associations, not claims of synonymy. Review same-sense usage and metadata before publication. Source membership is checked server-side against `oxford-membership.json`; future packs should extend that evidence file only after source verification.

The learner network never imports this file directly: it reads published database rows. Re-running an import does not overwrite existing rows. Import/link failures leave new words in DRAFT so they can be recovered through the creator page. No content migration or direct SQL update is required.
