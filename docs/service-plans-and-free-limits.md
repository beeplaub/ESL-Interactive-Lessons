# BrenUp services, plans, and free limits

**Inventory checked:** 2026-11-03
**Scope:** Services found in the repository configuration/code, plus services explicitly identified by the owner (including the current Vercel CPU allowance).
**Important:** The repository shows integrations, not the billing plan attached to each private account. Where the exact BrenUp account tier or quota cannot be verified from code, this document says so instead of guessing. Check each provider dashboard before making a budget decision. Limits and prices can change.

## Confirm these private account facts

The code cannot reveal actual billing subscriptions or usage balances. To complete the live-plan column with certainty, check:

1. Vercel team plan, CPU boost expiry, current 30-day usage, and Spend Management.
2. Supabase organization plan, per-project size/egress/storage, and inactivity status.
3. Cloudflare plan, Workers daily/monthly usage, R2 storage/operations, and TURN GB.
4. Google AI Studio: project tier, exact Gemini text/TTS/Live model quotas, usage, and billing.
5. Groq, OpenRouter, DeepSeek, Brevo, Azure Speech, and JaaS: active plan, remaining credits/quotas, and current model/resource limits.
6. Firebase project billing plan and whether GA measurement ID/FCM production config are enabled.
7. GitHub account/repository visibility and Actions usage.

Never paste API keys, `.env.local`, service-role credentials, or private learner data into this document. Keep only plan names, quota counts, renewal/reset dates, and links to provider dashboards.
